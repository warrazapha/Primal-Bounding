The Nameless

The Nameless, the Unnamable. This is an interesting word, it is itself a name, but it refers to that which is not nameable. The name unnamable does not grant any particular naming, we can only point, gesture in this direction. Not unnamed, unnamed is nameable, just not currently named. If you could name anything of the unnamable, then that would be nameable by definition. The name unnamable does not grant any naming, we can only point, gesture in this direction. We can’t say anything about the unnamable except that it permit no naming.

In order for something to be named, it must be able to be distinguished. It doesn’t* need mean it needs to be distinguished, things exist before we human name them. Uno, One both refer to, or point to the same entity and it exist before we named it. We could only name it, because it was nameable.

This naming conundrum is not unique to the unnamable, consider a system that was truly unpredictable, we can’t predict anything about that system except that it is unpredictable.

Bounding is an interesting thing, there is a real reason PEMDAS is important to know. This is what tells you what order to read mathematical sentences in. Parentheses go first, because every other act presupposes a bound to operate upon.

The Nameless is the beginning of Heaven and Earth. I have a great respect for the entities in question, and you will see why by the end of this. The entities we are discussing are primal entities and what I mean by that is these are all precursors, harbingers. So what is the first bounding?

The Primal Bounding

The name Unnamable itself gives us a hint to the only way such an entity could be “bounded”. We can’t name anything within it by definition, but we can and do talk about it so it has been conceptually bounded at minimum. The thing we talk about here, would be the primal bounding, the first bound. A bound is a named thing, but we can bound it similarly to the way the name does. We can only point to a limit.

This binding does not populate the unnameable, and while we can specify the bound, we know that anything nameable can’t reach into it. The Primal Binding. When we bound, we also distinguish. Primal Distinction.

The Primal Unity

The second binding, is related to the first. Logically inseparable. We have successfully bound, and in that binding, we have named. The first thing we have named, is that which cannot be named. The second binding is like the first, and it bind the Nameable. This also does not populate anything specific, there are no specific members, but the potentiality for members is established. Unnamed but Nameable, and not Unnameable. The Primal Unity.

The Unnamable we represent with a dot, that is the Primal Binding. The second binding is a circle around that dot, this is the Nameable and these constitute the Primal Unity.

The second bounding does not affect the Primal Bounding, the Primal Bounding remains unspecified, in its own ineffable way, and the Nameable contains all that is capable of being named, but names nothing specific.
